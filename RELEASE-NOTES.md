# ME-80 Patch Editor 0.2.0 beta

- Read the ME-80 system settings and select Direct or Catch knob operation, with readback verification. Press WRITE on the pedal to retain the setting after power-off.
- Added passive MIDI listening and read-only system-address probing in Settings diagnostics.
- Added developer-only discovery commands; these are not included in the installer.
- Reject incomplete system blocks and safely handle empty discovery responses.

Windows 11 x64, official BOSS ME-80 driver, and WebView2 required. This installer is unsigned. Physical pedal verification remains separate from automated tests. Back up your patches before testing.
